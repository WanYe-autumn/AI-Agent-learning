# Trade Review Assistant

一个使用 Python 编写的命令行交易复盘工具，用于记录交易并生成基础统计报告。

## 当前功能

- 录入多笔股票交易
- 校验股票名、价格和数量
- 计算每笔交易盈亏
- 计算总盈亏
- 计算交易胜率
- 找出盈利最高的交易
- 将报告保存为 JSON 文件
- 使用 pytest 对核心统计函数和输入解析进行自动化测试
## 运行方式

进入项目目录：

```bash
cd 02-trade-review-assistant
```

运行程序：

```bash
python main.py
```

按照以下格式输入交易：

```text
股票名,买入价,卖出价,数量
```

例如：

```text
beone,250,256,100
```

输入空行即可结束录入并生成报告。

## 项目结构

- `main.py`：程序入口和交互流程
- `models.py`：输入解析与数据校验
- `services.py`：盈亏、胜率等统计计算
- `io_utils.py`：保存 JSON 报告
- `requirements.txt`：项目依赖

## 已知问题

- 目前仅支持命令行操作
- 每次运行会覆盖之前生成的报告
- 盈亏计算暂未考虑手续费和税费
